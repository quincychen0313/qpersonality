# qPersonality v1.0

This package contains the first operational data layer for qPersonality.

## Files
- `question_bank_180.json` — 180 bilingual draft items (30 facets × 6 items).
- `scoring_engine_v1.json` — scoring, normalization, confidence, and RQI rules.
- `qpersonality_data_v1.ts` — ready-to-import TypeScript constants.

## Important
These are product-development draft items, not yet a validated psychological instrument.
Before public claims of reliability/validity, run pilot testing, item analysis, reliability analysis,
factor analysis, norming, and fairness / measurement-invariance review.

## Response Scale
1 = Not like me at all / 非常不像我
4 = Somewhat like me / 一半像我
7 = Very much like me / 非常像我
